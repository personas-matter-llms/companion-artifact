# Agents with Feelings? Personality and Emotion in Multi-Agent Software Teams

This directory contains the companion artifact for the paper **"Agents with Feelings? Personality and Emotion in Multi-Agent Software Teams"**.

- `task1_code_generation/`: code-generation workflow, public data, and analysis scripts.
- `task2_code_review/`: code-review workflow, public data, and analysis scripts.
- `paper_figures/`: scripts for generating the RQ1 and RQ2 distribution figures from the public data.

Install the Python dependencies once from this directory:

```bash
pip install -r requirements.txt
```

Run analysis scripts from the corresponding task directory. The mixed-effects model scripts additionally require R with the `lme4` package.
